# Godot Asset Library listing

Text and images for the submission form (https://godotengine.org/asset-library/asset/submit). The addon zip
is built by `tools/package_godot_addon.py` and attached to each GitHub release by the release workflow.

- **Title:** SpriteKiln
- **Category:** 2D Tools
- **Godot version:** 4.2
- **Version:** the release version (e.g. 0.1.0)
- **Repository host:** Custom
- **Repository URL:** https://github.com/LucasJRamos/spritekiln
- **Issues URL:** https://github.com/LucasJRamos/spritekiln/issues
- **Download URL:** https://github.com/LucasJRamos/spritekiln/releases/download/v0.1.0/spritekiln-godot-0.1.0.zip
- **Icon URL:** https://raw.githubusercontent.com/LucasJRamos/spritekiln/main/integrations/godot/assetlib/icon.png
- **License:** MIT
- **Previews:** `screenshot_walk.png`, `screenshot_attack.png` (raw URLs as above), and
  `showcase/huntress/turnaround.gif`

**Description:**

> Plays animated pixel-art sprites made with SpriteKiln (procedural 3D models described in YAML, rendered
> into 8-direction top-down or side-view pixel art): KilnSprite2D with exact per-frame durations, gameplay
> events (hit, step, windup...) on the right frame, sockets (muzzles, hands, impact points), mirrored
> directions, an emissive layer and normal-mapped SpriteFrames for Light2D. The editor plugin builds
> SpriteFrames and a ready scene from a render JSON dropped into the project, so the SpriteKiln command line
> is optional. A sample project is in the repository (examples/godot).
